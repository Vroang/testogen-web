# VISION — Веб-версия ТестоГена

## Цель
Веб-приложение, которое работает с ТОЙ ЖЕ базой данных Supabase,
что и Android-версия. Позволяет маме (и коллегам) заходить
с любого компьютера, видеть свои учебники, банк вопросов,
создавать тесты и экспортировать их в Word.

## Пользователь
Мама (учитель истории/обществознания). Возможно, её коллеги.
Вход — по email и паролю (тот же аккаунт Supabase, что в Android).

## Ключевое отличие от Android
- Данные синхронизируются через Supabase в реальном времени.
- Учебники, вопросы, темы — общие между телефоном и сайтом.
- Работает в браузере, ничего не надо ставить.

## Функционал (как в Android-версии)
- Вход в аккаунт (Supabase Auth).
- Библиотека учебников (список, загрузка PDF/DOCX/TXT,
  просмотр параграфов).
- Генерация вопросов из параграфов через ИИ (OpenRouter).
- Банк вопросов (список, фильтр по темам, редактирование).
- Сборка теста (варианты × вопросы, темы).
- Экспорт в Word (тест + ответы).

## Стек
- Vite + React 18 + TypeScript
- Supabase JS SDK
- Tailwind CSS
- Хостинг: Vercel

## Визуальный стиль
- Как в Android-версии: светлый фон, teal-акцент, крупные
  карточки, скругления ~16 px.

## Что НЕ делаем
- Не делаем PWA (установку на телефон) — это сайт, не приложение.
- Не делаем офлайн-режим на первом этапе.
- Не поддерживаем старые браузеры.

## Конечный критерий готовности
Мама заходит на сайт, вводит email и пароль — видит все свои
учебники и вопросы, которые есть на телефоне. Может
сгенерировать новые вопросы и экспортировать тест в Word.
