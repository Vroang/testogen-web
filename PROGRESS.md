## Что сделано (шаг 1)
- Экран входа (src/pages/LoginPage.tsx): поля Email и Пароль (скрыт
  точками), кнопка «Войти», логотип «Т» и заголовок «ТестоГен».

  не залогинен → /login, залогинен → /. Работает и при перезагрузке.
- Роутер (react-router-dom): маршруты / и /login с защитой.
- Главный экран (src/pages/HomePage.tsx) — заглушка + email вошедшего
  пользователя.
- Проверено: сборка без ошибок; открытие / без сессии перекидывает на
  /login; при неверном паролe сервер Supabase отвечает, красная ошибка
  показывается (ключ anon принимается — в браузере всё работает).

## Известные проблемы
- Проверка ключа Supabase через curl давала «Invalid API key», однако
  пользователь подтвердил, что ключ валиден, и реальный запрос из
  браузера (signInWithPassword) проходит: сервер отвечает ошибкой
  авторизации «Invalid login credentials» при неверном пароле — то есть
  ключ принят. Проблема была в способе проверки, игнорируем.
- Успешный вход в аккаунт проверяется только реальными учётными
  данными (email + пароль мамы) — механика редиректа после входа
  написана и симметрична проверенной защите, но глазами пока не видна.
